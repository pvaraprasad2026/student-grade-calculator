Student Grade Calculator
Project Description
The Student Grade Calculator is a Python application that calculates the total marks, percentage, and grade of a student based on marks entered for three subjects.

Features
Accepts student name
Calculates total marks
Calculates percentage
Assigns grade based on percentage
Displays student report
